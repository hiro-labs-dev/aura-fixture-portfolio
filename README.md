# aura-fixture-portfolio
Aura TEST FIXTURE — a **portfolio website** brief. No backend (website-kind).
Exercises the image-forward, gallery, NO-sidebar composition path.

## Brief
**Product:** personal portfolio for "Marcelo Reyes", an architectural photographer.
**Audience:** architecture firms + magazines hiring for shoots.
**Goal:** showcase work, drive inquiries.
**Tone:** moody, editorial, minimal — image-forward, lots of negative space.
**Key sections:** expressive hero, a masonry/gallery grid of projects, a project
detail view, a short about, a contact form. NO dashboard, NO sidebar.
